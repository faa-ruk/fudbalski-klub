# Fudbalski Klub

Web stranica fudbalskog kluba, izrađena u paru u sklopu projektnog zadatka iz predmeta Softversko inženjerstvo.

## Stranice
- `index.html` – početna (hero, o klubu, novosti)
- `tim.html` – igrači
- `utakmice.html` – raspored utakmica i tabela lige
- `kontakt.html` – kontakt forma s JavaScript provjerom

## Tehnologije
HTML5, CSS3, JavaScript, Git i GitHub

## Podjela posla
- **Adem Hadžić:** wireframe, početna stranica (`index.html`, `css/index.css`, `js/menu.js`), README
- **Faruk Hamza:** mockup, stranice Tim, Utakmice i Kontakt (`css/pages.css`, `js/script.js`)

## Pokretanje
Preuzmi projekt i otvori `index.html` u pregledniku.
